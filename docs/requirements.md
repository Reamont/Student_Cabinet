# Матрица требований

Статус кода и фактические доказательства разделены. Таблица описывает реализацию; результаты конкретных запусков фиксируются в `process-report.md` и выводе тестов. «Предусмотрено» не означает «проверено на публичном сервере».

| Требование | Реализация | Проверка | Доказательство |
| --- | --- | --- | --- |
| Вход, неверный пароль, выход | Django auth, LoginView, POST logout | Тест auth + оба аккаунта в браузере | Протокол тестов, login screenshot |
| Закрытые страницы | `student_required`, login redirect | Неавторизованный запрос каждой страницы | Тесты доступа |
| Два разных студента | `seed_demo`: alisa/maks, разные группы/результаты | Вход каждым и сравнение | Скриншоты кабинетов |
| Профиль | Profile, защищённый экран | Поля и отсутствие чужого профиля | Браузер + тест |
| Расписание: день/неделя | Lesson, серверный выбор по группе | Переключение и переход дат | Браузер + тесты |
| Текущее/следующее занятие | Расчёт относительно Moscow time | Контролируемые время/данные | Тест расписания |
| Пустой день, отмена, перенос | Поля отмены и прежних значений | Просмотр seed-периода | Скриншот расписания |
| Полезные актуальные даты | Seed относительных дат, реальное «сегодня» | Повторная команда заполнения | Тест seed + баннер периода |
| Разные состояния успеваемости | LearningResult с явным state | Оценка/зачёт/pending/empty/debt | Тест и экран успеваемости |
| Понятное среднее | Только пятибалльные оценки, Avg | Смешанные результаты | Тест среднего |
| Три типа заявок | RequestForm, StudentRequest.Kind | Успешные и ошибочные формы | Тесты, скриншоты |
| Проверка перед отправкой | Отдельный review экран | Ввод → review → submit | Браузерный сценарий |
| Сохранение заявки | БД + миграции | Перезагрузка, повторный вход, рестарт | Тест и протокол рестарта |
| Статусы, история, комментарии | StatusForm, RequestHistory | Статусы сотрудником; обязательная причина | Admin-тест и браузер |
| Ответ на уточнение | POST владельца, история ответа | Валидация и повторный POST | Тесты и request detail |
| Студент не ставит «Готова» | Белый список полей + admin permissions | Подмена user_id/status/role | Тест злоупотреблений |
| Чужие ID не раскрывают данные | Owner filters, 404 | А запрашивает заявку/уведомление/дедлайн Б | Тест изоляции |
| Уведомления четырёх категорий | Notification, фильтр, read_at на адресата | Фильтры, открыть, прочесть | Тесты и экран |
| Независимое прочтение | Отдельная Notification каждого адресата | Прочтение А не влияет на Б | Тест изоляции |
| План на сегодня | Правила по данным студента | Ссылки и причины, изоляция | Тест плана и dashboard |
| CSRF, escaping, cookie flags | Django middleware/templates/settings | POST без токена, XSS payload, headers | Security-тесты |
| Ограничение входа | DB-backed rate limiter | Порог, 429, admin login | Security-тесты |
| Idempotency | Подписанный UUID + unique constraint | Повтор подтверждения | Тесты формы |
| Телефон 360 px | Адаптивная сетка и нижняя навигация | Браузер: ширина/scrollWidth/основной сценарий | Мобильные скриншоты |
| Клавиатура и длинный текст | Labels, focus, переносы | Tab + длинные имена и объявления | Браузерный протокол |
| Инициализация без потерь | `seed_demo` не удаляет заявки/пароли | Два запуска + сравнение | Тест seed |
| PostgreSQL и production | Compose persistent volume, HTTPS/nginx | Реальный контейнер PG17/Gunicorn, cookie headers, check--deploy | Локально проверено; настоящий TLS и VPS ещё требуют проверки |
| Документация и процесс | README, AGENTS, docs | Сверка с фактическими файлами/результатами | Этот комплект |
| Демонстрационные документы | Необязательная загрузка не добавлена | Нет маршрута скачивания | Явное ограничение |
| Официальные условия/сроки | В задании только срок работы до 28 ноября | Нужна ссылка организатора | Не проверено по официальному источнику |
| Публикация | Подготовлены Docker/Compose/nginx и инструкция | HTTPS + сценарии + сеть РФ | Не выполнено без доступа владельца |

Факты о потребностях — продуктовые гипотезы, а не результаты интервью. Фактические человеческие действия указаны отдельно в `manual-work.md`.
