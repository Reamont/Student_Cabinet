# Демонстрация до пяти минут

До показа: запустите сервис, подготовьте два студенческих аккаунта и приватный аккаунт сотрудника в отдельных браузерных профилях. Не демонстрируйте файл окружения или пароль. Убедитесь, что seed-период актуален и есть пример изменения расписания. Все записи — вымышленные.

| Время | Действие | Что показать |
| --- | --- | --- |
| 0:00–0:25 | Экран входа, войти как `alisa` | Заметная маркировка прототипа, понятные поля, закрытые страницы |
| 0:25–1:00 | Главная | Ближайшее занятие, изменения, обязательства и «План на сегодня» с причинами и рабочими ссылками |
| 1:00–1:35 | Расписание и успеваемость | День/неделя, перенос до/после, отмена; оценка отличается от зачёта, ожидания и отсутствия данных |
| 1:35–2:35 | Создать справку/заявление | Выбор типа → ввод → проверка → отправка; номер, статус, история; обновить страницу и убедиться в сохранности |
| 2:35–3:20 | Сотрудник в отдельном профиле браузера | Найти заявку в `/admin/`, поставить «Нужно уточнение», написать причину; студент видит историю и уведомление |
| 3:20–3:55 | Ответ студента и готовность | Отправить уточнение; сотрудник ставит «Готова»; студент не выбирает этот статус сам |
| 3:55–4:30 | Второй студент `maks` | Другие профиль, группа, оценки и уведомления; чужая заявка по ID недоступна |
| 4:30–4:50 | Телефон 360 px | Нижняя навигация, читаемые формы и статусы, отсутствие горизонтального скролла |
| 4:50–5:00 | Ограничения и материалы | Нет настоящих данных/официальной выдачи документов; показать ссылку на отчёт и исходники |

Перед демонстрацией отрепетируйте шаги на актуальной базе; не удаляйте существующие заявки ради «чистого» показа. Для новой попытки создайте новую заявку. При публичном показе сотрудник вводит пароль вне записи экрана.

Показывайте только реально работающий сценарий. При недоступности хостинга используйте локальный экземпляр и прямо скажите, что публичная доступность не проверена. Картинки интерфейса не заменяют работающий прототип.
